# project-doc

Архитектурный репозиторий.

Архитектурный репозиторий - это средство управления архитектурной документацией, где хранится информация о структуре, стандартах и правилах системы.

 «Система управления лояльностью клиентов: архитектура для учета бонусных баллов, управления акциями и скидками, анализа активности клиентов».
