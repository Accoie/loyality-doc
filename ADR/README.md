# Архитектурные решения

В каталоге собраны записи архитектурных решений для системы управления лояльностью клиентов.

## Стандарт именования

Используется формат `YYYY-MM-DD-NN - Русское название решения.md`, например `2026-10-26-01 - Сервисная архитектура.md`. Дата и номер задают порядок, а русское название сразу показывает тему записи.
