# ADR-06: Развертывание и резервные копии

**Дата:** 26 октября 2026 г.

**Статус:** Принято

## Контекст

Система должна работать постоянно, а подтвержденные бонусные операции нельзя терять. В лабораторной работе нужно показать резервное копирование, но подключать облачные сервисы для имитации не будем.

## Рассмотренные варианты

1. Хранить копию только на компьютере, где запущена система.
2. Хранить копии на компьютерах двух участников проекта.

## Решение

Сервисы запускаются на компьютере для демонстрации. PostgreSQL является основной базой, Redis используется для временных данных.

Резервное копирование выполняется просто:

- полная копия PostgreSQL создается каждый день;
- копия отправляется на компьютеры двух участников проекта;
- на каждом компьютере хранится отдельная копия;

Покупка может быть проведена без списания баллов, если сервис временно недоступен (LIM02).

## Обоснование

Две копии на разных компьютерах позволяют показать работу резервирования без подключения платных облачных сервисов. В реальной системе эти два компьютера можно заменить двумя независимыми облачными хранилищами.

## Последствия

- Нужно назначить участника, который запускает ежедневное копирование.
- При недоступности одного компьютера остается копия на втором.
- Для учебной работы достаточно одной проверки восстановления перед сдачей.

## Проверка

Проверяется наличие копии на компьютерах двух участников и успешное восстановление базы из одной из копий.
